代码

行内 pip install nothing 这样写；代码块会带语言标签：

python
def hello(name: str) -> str:
    """写点代码也不怕，整站零依赖。"""
    return f"你好，{name}！"

print(hello("主人"))

小技巧

  • 正文里单独写一行 --- 会变成分割线，所以别拿它当排版空行
  • 一篇文章里二级标题超过 3 个，文章页会自动出现「目录」
  • 想让某段话出现在首页摘要里，就在编辑器的「摘要」框里写；留空则自动取正文开头
