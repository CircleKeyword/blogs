你好呀 👋

这是你的本地静态博客。整站没有任何后端依赖：写完文章点一下「发布并生成」，site/ 目录里就会多出真实的 HTML 文件，拷到 U 盘、发给同学、扔到任何静态托管（GitHub Pages / Netlify / 自己的服务器）都能直接跑。

三个入口

想做什么双击哪个文件
写新文章 / 改文章启动编辑器.bat
只重新生成静态站点生成博客.bat
直接看博客打开博客.bat

编辑器能做什么

  • 左侧列表选文章，右边直接改；标题、日期、标签、摘要都是表单字段，不用手写 frontmatter
  • 写好 slug（链接名）后会自动去重，日期改了文件名也会跟着改，不会留一堆重名文件
  • 右边是实时预览，用的是最终产物的同一套样式，所见即所得
  • 「存为草稿」勾上就只在编辑器里留着，站点上不会出现，放心写
  • Ctrl + S 保存并生成，Ctrl + Enter 同样发布，Ctrl + B / I / K 是加粗 / 斜体 / 链接

文章是纯文本 Markdown 存在 posts/ 里的，用记事本、VS Code、Obsidian 直接改也一样，编辑器只是给你省事。

图片放哪

把图片丢进 posts/ 旁边任意位置都行，正文里用相对路径引用即可，例如：

markdown
![截图](images/shot.png)

生成的 site/posts/xxx.html 会原样引用这个路径，所以图片记得跟 posts/ 一起拷走。
